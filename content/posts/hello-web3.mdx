## 为什么写这个博客？

作为一名 Web3 开发者，我发现这个领域的知识更新非常快。今天学的 ERC-20，明天可能就要研究 ERC-4337 账户抽象了。

所以我决定用「边学边写」的方式，把学习过程记录下来：

1. **巩固知识** - 写出来才知道自己真的懂了没
2. **帮助他人** - 也许我踩过的坑能帮你省点时间
3. **链上存证** - 每篇文章都可以哈希上链，这很 Web3

## 这个博客的技术栈

```
前端: Next.js 15 + Tailwind CSS + MDX
存储: 静态文件 + IPFS 备份
托管: Cloudflare Pages
存证: Polygon (ethers.js)
```
